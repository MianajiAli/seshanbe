# Restaurant Menu Frontend

This project is a frontend web application built to display a restaurant menu using the **SnappFood API**. The app allows users to view menu items, categories, and place orders. It's designed to showcase the restaurant's offerings with a smooth user experience and clean design.


![image](https://github.com/MianajiAli/seshanbe/assets/87234097/9374d60d-b2d4-4b9d-9619-469b71dfc4dc)




## 🚀 Getting Started

Follow these instructions to get the project up and running locally on your machine.

### Prerequisites

Make sure you have the following installed:
- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) (comes with Node.js)



### Running the App

To start the development server, run:

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser to view the restaurant menu.



## 🛠 Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Vite**: Build tool that provides a fast development environment.
- **Tailwind CSS**: Utility-first CSS framework for custom styling.
- **React Router**: For handling navigation and routing in the app.



## 🎨 Features

- **Dynamic Menu**: Fetches the restaurant menu from the SnappFood API and displays it in a user-friendly way.
- **Categories**: Shows different categories (e.g., Appetizers, Main Courses, Desserts, Drinks) to organize the menu.
- **Order Summary**: Allows users to review and confirm their order before submitting it.
- **Search Functionality**: Users can search for specific menu items by name.
- **Responsive Design**: The app is optimized for both desktop and mobile devices.
- **User-Friendly Interface**: Clean and modern UI with smooth animations and transitions.
